01

Introduction

Industrial security has evolved from simple CCTV to integrated IoT systems. However, most affordable solutions still lack real-time environmental awareness and dynamic camera movement. This project bridges that gap using the XIAO ESP32-S3 Cam, a dual-core processor with 8MB PSRAM and 2MP camera.

We integrated:

PIR sensor — human motion detection; swappable with HC-SR04 ultrasonic
DHT11 — temperature (0–50°C) & humidity (20–90% RH)
LDR — light intensity (analog 0–4095)
Rain sensor — digital output (LOW = wet)
360° servo — adjustable speed (90=stop, 70–110=slow, 0–180=full)

The system hosts two web servers: Port 80 (REST API + dashboard) and Port 81 (MJPEG stream, ~15 fps, 480×320). Motion alert latency <0.5 sec.

02

Problem Statement

Real-World Scenario

A small warehouse stores electronic components. One night, rain seeps through the roof — but the CCTV shows only the entrance. By the time someone checks, the components are damaged. Another scenario: An intruder enters from a side alley — fixed cameras miss him entirely.

Specific problems:

Blind Spots

Fixed cameras cover only 60–90°; intruders exploit this.

No Environmental Feedback

Temperature, humidity, rain, light changes go unnoticed.

No Remote Intervention

Cannot rotate camera or sound alarm from your phone.

High PTZ Cost

Professional Pan-Tilt-Zoom cameras cost ₹15,000+.

Our Solution

A single ESP32 board that does everything — video + panning + sensors + alerts — for under ₹3,000.
