# 🚀 IoT-Based Industrial Security System

## 📌 Project Title
**IoT-Enabled Industrial Security System using ESP32-S3 CAM with Real-Time Monitoring and 360° Surveillance**

---

## 📖 Abstract
Industrial security is a major concern due to increasing risks such as theft, unauthorized access, and environmental damage. Traditional CCTV systems are expensive and lack real-time monitoring and remote control capabilities.

This project presents a low-cost IoT-based surveillance system using the ESP32-S3 CAM. It integrates multiple sensors including PIR, DHT11, LDR, and a rain sensor to monitor both security and environmental conditions. A 360° servo-mounted camera ensures complete area coverage. The system provides live video streaming, real-time data monitoring, and remote control through a web-based dashboard.

---

## 🧠 Methodology

1. System initialization on power ON  
2. ESP32 connects to Wi-Fi  
3. Camera starts live streaming  
4. Sensors collect environmental data  
5. Data is updated on web dashboard  
6. Motion detection triggers alert system  
7. Servo rotates for 360° monitoring
